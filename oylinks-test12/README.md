# Зеркало документов Oylinks

Этот каталог создаёт и поддерживает Oylinks. Он **зеркало**, а не рабочая копия:

* отсутствующий файл будет восстановлен;
* изменённый файл будет перезаписан серверной версией;
* любой посторонний файл внутри `.oylinks` будет удалён.

Прежние байты сохраняются в карантине вне репозитория.

**Правки здесь в приложение не попадают.** Обратного направления не существует:
изменить документ можно только в Oylinks.

Версия формата — `schema/format-version.txt`.
